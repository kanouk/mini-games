# せいぶせん うんてんし

西武線が大好きな子どものための、ブラウザで遊ぶ運転ゲームです。「しんかんせん うんてんし」をもとにしていて、1つのHTMLファイルだけで動きます。

## 遊び方

- タイトル画面で「はじめる」を押すと始まります（最初は急行 池袋→飯能）。「でんしゃを えらぶ」からは、路線・種別・乗る駅・降りる駅・車両・出発時刻を選べます。
- 「しゅっぱつ！」を押すと発車ベルが鳴り、ドアが閉まって走り出します。押し続けると加速し、止まる駅に近づくと自動で止まります。通過駅はそのまま通り過ぎます。
- 押し続けたままにすると、乗り降りが終わったあと自動で次の駅へ向かいます。
- 「じどう」をオンにすると、ボタンを押さなくても走ります。
- 終点に着くと折り返します。

## できること

- 11の運転系統（西武線全12路線）
  - 池袋線・西武秩父線（池袋〜西武秩父）、西武有楽町線・池袋線（小竹向原〜西武秩父）、池袋線・豊島線、池袋線・狭山線
  - 新宿線、新宿線・拝島線、国分寺線、西武園線
  - 多摩湖線、山口線（レオライナー）、多摩川線
- 種別と停車駅：各停・準急・通勤準急・快速・通勤急行・急行・快速急行・特急ちちぶ・特急むさし・特急小江戸・S-TRAIN・拝島ライナー・臨時特急（ドーム）
  - 停まれない駅や、走らない向き（通勤急行は上りだけ など）、走る時間帯（S-TRAIN、拝島ライナー など）を反映しています。乗り換えなしで行けない2駅の組み合わせは選べません。
  - 地下鉄に乗り入れる列車は、行き先を「新木場」「豊洲」「元町・中華街」と表示します。
- 車両：001系 Laview、10000系 ニューレッドアロー、40000系、30000系 スマイルトレイン、20000系、6000系、2000系、9000系、新101系、4000系、7000系、8000系、8500系 レオライナー。種別ごとに実際に走る車両だけを選べます。
- 駅ナンバリング付きの駅名標、車体横の種別・行先表示、時刻表（通過駅は「レ」）、遅れと回復運転
- 車内チャイム、日本語と英語のアナウンス（「所沢から先は各駅に止まります」なども）、車内表示器、車掌さんの声、警笛
- 踏切（警報機のカンカン）、正丸トンネルなど秩父の山のトンネル、地下の西武有楽町線、入間川、狭山茶の茶畑、武甲山、ドーム、多摩湖
- 高架区間では線路と電車がなめらかに上がり、橋脚・高架下の道路が現れます。高架・勾配上には踏切を出しません。
- ときどき、乗ろうとしてつまずき、その電車に乗り遅れる人が現れます（候補がいる停車の約8％・1人まで）。すぐに起き上がって電車を見送り、ホームを離れます。
- 駅と駅の間の長さは、実際の営業キロに合わせて変わります（都心は短く、山の区間は長い）。
- 緊急停止（踏切の非常ボタンなど理由を選べる）、現在地の地図、全画面表示

## ファイル

| ファイル | 内容 |
|---|---|
| `seibu.html` | ゲーム本体（HTML・CSS・JavaScriptを1ファイルにまとめたもの） |
| `tests/data.test.js` | 駅データ・停車駅・時刻のルールを確かめる自動テスト |
| `tests/passengers.test.js` | 転ぶ頻度・乗降・発車待ち・見送り・描画状態を確かめる自動テスト |
| `tests/browser.test.html` | 保存キーを隔離し、スマートフォンとパソコンで転倒から次駅到着までを確認するブラウザテスト |

## テスト

```sh
node tests/data.test.js
node tests/passengers.test.js
```

ブラウザテストは HTTP サーバー経由で `tests/browser.test.html` を開き、「確認する」を押します。`?preview=fall` と `?preview=missed` では、それぞれの演出を静止した状態で確認できます。本番用の保存データは変更しません。

## 注意

- 高架の代表区間として、池袋線の桜台付近〜大泉学園付近と、新宿線の東村山駅付近の下り線を反映しています。高架の境界・高さ・勾配は遊びやすさを優先した近似で、全線の高架橋・盛土を網羅したものではありません。池袋線に直通する系統や折返しでも共通の地形を使います。
- 高架区間の資料（2026-11-05確認）：[池袋線連続立体交差事業・複々線化事業](https://www.seiburailway.jp/safety/continuousgradeseparation/shakujii-koen/)、[東村山駅付近の下り線高架化](https://www.seiburailway.jp/newsroom/news/20250409_higashimurayamarenritu/)、[2026年の高架化効果報告](https://www.seiburailway.jp/file.jsp?id=27046)。新宿線上り・国分寺線・西武園線の工事中部分は高架として扱いません。

- 停車駅は2025年3月15日のダイヤ改正（2026年11月時点）をもとにしています。時刻は駅間の距離と最高速度から計算した目安で、本物の時刻表ではありません。最高速度もゲーム用の目安です。
- 次の点は資料によって違いがあり、多数の資料に合わせています。
  - 池袋線 通勤急行は練馬を通過
  - 新宿線 快速急行（土休日朝の下り1本）は航空公園を通過
  - 土休日の S-TRAIN は石神井公園に停車・横瀬を通過
- 臨時列車（ドーム試合日の特急・急行など）は、走る日が決まっていません。
- 車両の絵は、色や形の特徴をかんたんにしたものです。8500系の色など、細かいところは本物と違います。
- 2027年春には特急小江戸が「トキイロエクスプレス」に変わる予定です（10000系は定期運行終了の予定）。
- 駅データ（営業キロ・駅番号・位置）と停車駅は [TrainLCD/StationAPI](https://github.com/TrainLCD/StationAPI) のデータをもとに、鉄道ニュースサイトなどで確かめています。
