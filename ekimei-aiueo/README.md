# えきめい あいうえお

電車の名前や駅名を指でなぞる、未就学児向けのひらがな練習アプリです。[Issue #5](https://github.com/kanouk/mini-games/issues/5) の試作（`32b31cd`）を基に作りました。

`ekimei.html` をブラウザで開くだけで動きます。アプリのコード、83文字の筆順データ、挿絵はHTML内に含まれ、ビルドやデータ取得のAPIは不要です。書体はGoogle Fontsから読み込み、接続できない場合は端末の書体で表示します。

## 遊び方

1. 「はじめる」を押し、しんかんせん・えき・あいうえお・むかしの しんかんせんから選びます。
2. 「えき」では、まず新幹線の路線を選びます。好きなマスを選ぶと、その言葉を読み上げます。
3. 黄色の丸から、水色のレールを指でなぞります。🚃ボタンは今の一画のお手本です。お手本の途中でもなぞり始められます。
4. 言葉を最後までなぞるとシールが付きます。迷っても回数は減りません。続けて2回迷うと、自動でお手本を見せます。

現役の新幹線名19語、引退した列車名5語、10路線の駅名148マス、清音46文字の合計218マスがあります。新幹線名には路線名と「1992年開業」のような年を添え、引退した列車名には引退年も表示します。新幹線としてその名前で走り始めた順に並べています。引退した列車名は別のシールちょうなので、追加しても現役19語の達成度は下がりません。濁音・半濁音・小さい字も、それぞれ専用の筆順でなぞります。

## シールちょう・路線全体の昇格

同じシールちょうの全マスを1回ずつ完成すると「はじめの メダル」に昇格し、一覧カード・路線カード・マスの上のステータスが青く変わります。その後も全マス3・5・10・20・40回で、わくわく・銅・銀・金・虹のメダルへ進みます。駅は路線ごとに判定します。最後の1マスを完成したときは、メダルと紙吹雪の画面・音声でお祝いします。

次の段階まで「あと何マスか」を表示します。すでに達成している保存記録も、その回数から正しい状態を表示します。同じ段階のお祝いは繰り返さず、次の昇格時にまた祝います。

## おうちの人の設定

タイトル右下の⚙から変更します。

| 設定 | 内容 |
|---|---|
| なぞりの判定 | 「ひろい」は始点・終点・線からの距離・通過率を緩めます |
| こえ | 読み上げのオン・オフ。効果音は別に鳴ります |
| おてつだい | 自動で減らすか、太いレールなどの補助をずっと表示するか |
| おてほんを最初に見せる | 補助が最も多い段階で、字に入って0.9秒後に自動で一画を見せます |

練習回数は1・3・5・10・20・40回でマスの見た目が変わり、5回で銅・10回で銀・20回で金・40回で虹色になります。自動補助は5回で点線、10回で影、20回で白紙へ進みます。白紙でも同じ筆順で判定します。

1回は「言葉または1文字のマスを最後までなぞった回数」です。言葉を完成させると、含まれる文字の「あいうえお」のマスにも加算します。濁音・半濁音・小さい字は元の字にまとめ、同じ字は1語につき1回です。この派生加算は合計回数には重ねて数えません。

記録と設定は端末の`localStorage`（キー`ekimei-aiueo`）だけに保存し、外部へ送信しません。試作の同じキーの記録も読み込みます。保存形式・既存の列車名や東海道のキーは変えていません。画面の表示順やメダルは既存の`counts`から計算し、表示・読み込みだけで保存を書き換えたり、達成フラグを追加したりしません。保存が使えないブラウザでも、その回は遊べます。「きろくを ぜんぶ けす」は確認後に回数と日付を消し、設定は残します。時刻は端末の現地日付を使います。

## 検証

```sh
node ekimei-aiueo/tests/strokes.test.js
node shinkansen-untenshi/tests/schedule.test.js
node shinkansen-untenshi/tests/emergency.test.js
```

筆順の形式・画数・全題材の文字対応、判定の向きや許容幅、補助段階、記録の重複防止・保存データの読み込み、シールちょう全体の昇格、列車名の表示順、運転士ゲームの全10路線との一致を検査します。出題語で3回未満しか使われない清音は、警告一覧として表示します。

HTTPサーバーで公開した`ekimei-aiueo/tests/browser.test.html`を開き、「テストを実行」でブラウザ操作も検証できます。400px・1024pxの各幅で全218マスをSVGの実パスに沿ってなぞり、記録・4設定・白紙の判定・2回迷った際のお手本・途中で戻る操作・保存禁止時の動作、旧形式の記録の保持、全6段階の路線昇格などを検査します。画面遷移のタイマーはテスト用に短縮し、保存キーを分離して既存の記録を変更しません。端末での指の操作と声の聞こえ方は別途確認してください。
