ソウスケゲームズ ／ あたらしいアプリの企画

えきめい あいうえお

電車のことばを、指で「なぞって」おぼえる。文字の形がレール、指が電車。書き順どおりに走らせると駅名ができあがり、アナウンスが流れる。

中心は なぞり書き。シールちょうは「なぞった記録」がたまる場所

▶ 本番イメージの試作アプリ（説明文なし・音声つき）を開く

さわって確認するモック 1：レールなぞり（アプリの中心）

黄色い● のスタート駅から、水色のレールの上を指（マウス）でなぞってください。1本なぞるごとにレールが線路になり、文字が全部できると読み上げて次の字へ進みます。言葉ができあがると電車が走って、下のシールちょうに1回ぶん記録されます。まちがえても減点はなく、やりなおすだけです。

さわって確認するモック 2：シールちょう（なぞった記録がたまる）

上でなぞった言葉が、ここに記録されます。マスを直接タップしても1回ぶん進むようにしてあるので、たくさん練習した先の見え方（銅・銀・金）もここで確かめられます。言葉を練習すると、含まれる文字の「あいうえお」シートも一緒に進みます。

シールちょう
マス＝言葉1つ。なぞった回数で見た目と「おてつだいの量」が変わる

なぞり書きの設計（ここが本体）

画面

  • 文字の形がレール。一画ずつ、太いレールと枕木で描く。今なぞる一画だけ水色に光り、スタート駅は黄色い●、画数は番号で示す。
  • 指が電車。なぞっている間、指先に小さな電車がついてきて、走った部分が線路に変わる。
  • 一画できるごとに「カタン」。全部できると文字が大きく光って読み上げ（「と」）。言葉がそろうと「つぎは、とうきょう」のアナウンスと発車。
  • おてほんボタン。電車が自動で線路を走って書き順を見せる。何回でも押せる。

判定（失敗なし・でも甘すぎない）

  • スタート駅の近くから始めたか。違えば「●から はじめよう」と光らせてやり直し。
  • レールの上を、順番に、だいたい通ったか（レールの太さぶんの許容。7割通れば合格）。
  • 終点の方向に進んだか（逆走は不合格、ただし責めずにおてほんを流す）。
  • 不合格は「もういちど」だけ。減点も×もない。3回続けて迷ったら自動でおてほんが走る。

繰り返すほど「おてつだい」が減る

同じ字を何度もなぞる意味を、見た目のメダルだけでなく練習の中身に持たせます。マスの段階に連動して補助が減ります。

〜銅の手前太いレール・番号・スタート●・おてほん
銅から細い点線のレールだけ。番号は残す
銀からうすい影だけ。書き順は自分で
金から何もない白紙に、声だけを聞いて書く

白紙でも、判定はこっそり同じレールで行います。できたときの「見ないで書けた！」がいちばん大きなごほうびです。

字形と筆順データ

  • 見本の字は教科書体に近い Klee One（このページの文字）。丸ゴシックは学習用の形と差があるため使わない。
  • レールの座標は、筆順つきの KanjiVG（ひらがな・カタカナ収録）をそのまま使う。このモックの4文字がその実物で、同じ手順でひらがな46・カタカナ46・濁音・小さい字ぶんを機械的に取り込める。字形の精度は手作業ではなくデータに頼るので、全文字この品質になる。
  • 筆順データ出典：KanjiVG © Ulrich Apel、CC BY-SA 3.0。アプリ内にも同じ表記を入れる。
  • 小さい「ょ」「っ」は同じレールを小さく右下に置く。長音「ー」は一直線のレール。

ルール

  • 1回＝言葉を最後までなぞること。途中で迷っても、やり直して書き終えれば1回。減ることはない。
  • 言葉をなぞると文字も進む。「はやぶさ」で、は・や・ふ(ぶ)・さ の4マスにも1回ずつ。
  • シートのメダルは全マスの最低値。本人の称号は合計回数：けんしゅうせい → しゃしょう(30) → うんてんし(100) → しんかんせん うんてんし(250) → していん(500) → えきちょう(1000)。

たくさん なぞりたくなる工夫

  1. 1回が短い。「しゅっぱつ」1タップで言葉5つ、約2分。終わると「つぎの えきへ」だけが出て1タップで続く。途中でやめても回数は残る。
  2. おてつだいが減っていく。同じ字でも、点線 → 影 → 白紙と難しくなるので飽きない。「見ないで書けた」が次の目標になる。
  3. 「あと○かい」の予告。次のメダルが近い言葉に黄色いタグ。出題にも優先して混ざる。
  4. 出題は自動でちょうどよく。回数が少ない言葉・前に迷った言葉・メダル目前の言葉を混ぜる。
  1. 好きな字・言葉を直接なぞれる。シールちょうのマスをタップすれば、その言葉だけを何度でも。
  2. できた瞬間の演出。一画ごとに「カタン」、文字で光って読み上げ、言葉で電車が発車。メダルで電車が横切りファンファーレ。
  3. ごほうびが次につながる。シートが銅で次の路線が開く。取った車体色は「しんかんせん うんてんし」でも使える。
  4. きょうの しゅっぱつ と おうちの人むけの きろく。1日の最初のなぞりで日付スタンプ。どの字を何回なぞったかを見られる画面。

なぞりを支える3つのサブモード（後から）

えきめいひょう クイズ（よむ）

なぞる前のウォームアップ。駅名標の穴に入る字を3択で。まだ書けない字でも読む練習になる。

アナウンスを きいて えらぶ（きく）

音声だけで駅名標を選ぶ。「白紙に声だけで書く」段階への橋わたし。

ことばの れんけつ（ならべる）

なぞった字の車両を連結して言葉にする。なぞりのごほうびとして出す。

どのモードで解いても同じ1回として数えますが、中心はなぞりです。出題5問のうち最低3問はなぞりにします。

決めてほしいこと

  • なぞりの判定の厳しさ。モックの「レールの7割を順に通る」くらいか、もっと甘く／厳しくするか。実際に上のモックで試した感触を教えてください。
  • おてつだいが減るタイミング。銅(5回)で点線、銀(10回)で影、金(20回)で白紙、の速さでよいか。
  • 最初はひらがなだけでよいか。カタカナの筆順データは後から足す案です。
  • 称号の名前とアプリ名。けんしゅうせい〜えきちょう、「えきめい あいうえお」のままでよいか。
