# やまのてせん うんてんし

山手線が大好きな子どものための、ブラウザで遊ぶ運転ゲームです。「せいぶせん うんてんし」と同じ遊び方・同じ作りで、1つのHTMLファイルだけで動きます。

## 遊び方

- タイトル画面で「はじめる」を押すと始まります（最初は内回り 東京→新宿）。「でんしゃを えらぶ」からは、むき（内回り・外回り）・乗る駅・降りる駅・出発時刻を選べます。
- 降りる駅で乗る駅を押すと「いっしゅう」になり、山手線を一周して乗った駅に戻るとゴールです。
- 「じどう」がオフのときは、駅に着いたら「ドアを あける」を押します。乗り降りが終わったら「ドアを しめる」を押し、閉まってから「しゅっぱつ！」を押すと走り出します。最初の駅ではドアが開いています。
- 閉まる途中は「ドアを あけなおす」で開け直せます。走行中はドアを操作できません。
- 「しゅっぱつ！」を押し続けると加速し、次の駅に近づくと自動で止まります。
- 「じどう」をオンにすると、ドアの開閉と発車も自動で行います。
- **降りる駅（ゴール）に着くと「ゴール！」と出て、電車はそのまま山手線を回り続けます**（終点で折り返す西武線とはここが違います）。乗った駅に戻るたびに「○しゅう！」と出ます。

## できること

- 山手線の全30駅（JY01 東京〜JY30 有楽町。JY26 高輪ゲートウェイを含む）
- 内回り（東京→上野→池袋→新宿）と外回り（東京→品川→渋谷→新宿）。行き先は実際の案内と同じく「上野・池袋方面」のように、この先の大きな駅（東京・上野・池袋・新宿・渋谷・品川）2つで表示します。
- 車両はE235系（11両・4ドア、黄緑のドア）
- 駅ナンバリング付きの駅名標、車体横の行き先表示、時刻表（ゴールの駅に🏁）、遅れと回復運転
- 車内チャイム、日本語と英語のアナウンス、主な乗り換えの案内（池袋で西武池袋線、高田馬場で西武新宿線など）、車内表示器、車掌さんの声、警笛
- 全駅のホームに車掌さんが立ち、ドアの操作中に合図します。
- ホームドア（下の表）
- 踏切は、山手線に1つだけ残る駒込〜田端の「第二中里踏切」だけを出します（駒込から約400m）。
- 高架：東京〜上野、浜松町〜有楽町〜東京、渋谷駅付近。周回のつなぎめ（東京駅）でも線路の高さが途切れません。
- 景色：赤レンガの駅舎（有楽町〜東京〜神田）、赤と白の電波塔（新橋〜高輪ゲートウェイ）、高い電波塔（御徒町〜西日暮里）、新宿の高層ビル、原宿の森、神田川・目黒川
- ときどき、乗ろうとしてつまずき、その電車に乗り遅れる人が現れます（候補がいる停車の約8％・1人まで）。「あっ！」の声は西武線ゲームと同じ合成音声です。
- 駅と駅の間の長さは営業キロに合わせて変わります。
- 緊急停止（踏切の非常ボタンなど理由を選べる）、現在地の地図（山手線の輪）、全画面表示

## ホームドア

2026年3月末時点で、山手線は64ホーム中58ホームに整備済みです。

| 駅 | ゲームでの扱い |
|---|---|
| 新宿・渋谷 | 改良工事のため未設置。ホームドアを描きません |
| 大崎 | 1・3番線は整備済み、2・4番線は未整備（2026年度に整備予定）。ゲームでは整備済みのホームを代表として、稼働中で描きます |
| 上記以外の27駅 | 稼働中 |

資料：[山手線のホームドア：基本情報（ycs3120）](https://ycs3120.com/feature/platform-doors/jr-east/yamanote/)、[新宿・渋谷にない理由（鉄道コム）](https://topics.smt.docomo.ne.jp/article/tetsudo/trend/tetsudo-Column-1526)、[渋谷駅は2028年度までに設置（シブヤ経済新聞）](https://www.shibukei.com/headline/19004/)、[大崎2・4番線を含む2026年度計画（Impress Watch）](https://www.watch.impress.co.jp/docs/news/2092833.html)、[池袋5・8番線の稼働（2nd-train）](https://2nd-train.net/topics/article/71638/)

## 3Dモード（裏コマンド）

- タイトル画面の何もないところを **10回続けてタップ（クリック）** すると、景色を立体で描く3Dモードに切り替わります。もう一度10回タップすると元の2Dに戻ります。選んだモードは次回も引き継がれます。
- 遊べること・操作・時刻・音は2Dとまったく同じです。変わるのは絵と、画面の表示のデザイン（落ち着いた配色）だけです。
- 3Dで描くもの：E235系、高架と橋脚、踏切、ホームドア、駅名標、車掌さん、街並み、遠景のビル街（新宿付近は高いビル）
- 2Dの電波塔・赤レンガの駅舎は、3Dでは手前のビルに隠れて見えないため描いていません。
- 3Dモードは `yamanote-3d.js` と `../vendor/three/three.module.min.js`（three.js r170、MITライセンス。ほかのゲームと共用）を、切り替えたときにだけ読み込みます。**HTTPサーバー経由で開いたときだけ** 使えます。ファイルを直接開いた場合や WebGL が使えない端末では、2Dのまま遊べます。
- `yamanote-3d.js` は西武線ゲームの `seibu-3d.js` をもとにしています。空・光・素材・人・木や家の作りは共通なので、共通部分を直すときは `shinkansen-3d.js`・`seibu-3d.js` も直します。

## ファイル

| ファイル | 内容 |
|---|---|
| `yamanote.html` | ゲーム本体（HTML・CSS・JavaScriptを1ファイルにまとめたもの） |
| `yamanote-3d.js` | 3Dモードの描画（ゲームの進行は `yamanote.html` のまま） |
| `assets/yamanote-cover.webp` | トップページのカバー画像 |
| `assets/passenger-ah.mp3` | つまずいた人の声（`yamanote.html` にも埋め込み済み） |
| `tests/data.test.js` | 駅データ・営業キロ・環状運転・時刻・高架・踏切・ホームドアを確かめる自動テスト |
| `tests/passengers.test.js` | 転ぶ頻度・乗降・発車待ち・見送りを確かめる自動テスト |
| `tests/audio.test.js` | 埋め込み音声が元ファイルと同じか確かめる自動テスト |
| `tests/browser.test.html` | 保存キーを隔離し、スマートフォンとパソコンの幅で一周運転・ゴール・ホームドア・踏切を確認するブラウザテスト |

## テスト

```sh
node tests/data.test.js
node tests/passengers.test.js
node tests/audio.test.js
```

ブラウザテストは HTTP サーバー経由で `tests/browser.test.html` を開き、「確認する」を押します（一周を2回走るので1〜2分かかります）。`?preview=fall`・`?preview=missed`・`?preview=goal` で、その場面で止めて確認できます。本番用の保存データは変更しません。

## 注意

- 駅間の距離はJRの営業キロ（東京〜品川 6.8km、東京〜田端 7.1km、品川〜田端 20.6km、一周 34.5km）です。駅の位置（地図用）は [TrainLCD/StationAPI](https://github.com/TrainLCD/StationAPI) のデータを丸めたものです。
- 時刻は駅間の距離と最高速度（90km/h）から計算した目安で、本物の時刻表ではありません。一周はおよそ59分です。出発時刻は4:30〜24:00から選べます（ゲーム用の目安）。
- 「池袋止まり」「大崎止まり」など車庫に入る電車はまだ選べません。
- 発車メロディは駅ごとの本物の曲を使わず、共通のベル音です。
- 運転士の交代は入れていません（交代する駅を資料で確かめられていないため）。
- 京浜東北線・新幹線などの並走する電車は、まだ走りません。
- 第二中里踏切は、代わりの跨線橋ができたあと（2029年度ごろの予定）に廃止される予定です。資料：[乗りものニュース](https://trafficnews.jp/post/87856)
- 車両・電波塔・駅舎の絵は、色や形の特徴をかんたんにしたものです。
- カバー画像はゲームの2D画面から作ったもので、ほかのゲームの水彩画とは画風が違います。
