# 山手線ゲームの素材

## カバー画像

`yamanote-cover.webp` は、山手線E235系と東京タワーのある街並みを描いた、水彩の絵本風の表紙画像です。新幹線・西武線ゲームの表紙を画風の参考にして生成しました。

- 作成日：2026-11-26
- 作成方法：内蔵の画像生成ツールで生成し、960 × 640 のWebPに変換
- 生成プロンプト：`yamanote-cover-prompt.txt`

## ゲーム中の音声

| ファイル | 内容 |
|---|---|
| `passenger-ah.mp3` | つまずいた人の「あっ！」。西武線ゲームの `seibu-untenshi/assets/passenger-ah.mp3` と同じファイル（macOS の `say`、Kyoko で作成した合成音声） |

同じデータを `yamanote.html` 内にも埋め込み、「おと」設定に従って再生します。
