# 山手線ゲームの素材

## カバー画像

`yamanote-cover.webp` は、ゲームの2D画面（内回り 田町→浜松町を走るE235系と電波塔の景色）を、表示類を隠して 960 × 640 で撮影し、WebP に変換したものです。

- 作成日：2026-11-25
- 作成方法：Playwright（Chromium）でゲームを開き、`.hud`・`.route`・`.banner`・`.bar` を非表示にして撮影
- ほかのゲームのカバー（水彩の絵本風）とは画風が違います。揃える場合は差し替えてください。

## ゲーム中の音声

| ファイル | 内容 |
|---|---|
| `passenger-ah.mp3` | つまずいた人の「あっ！」。西武線ゲームの `seibu-untenshi/assets/passenger-ah.mp3` と同じファイル（macOS の `say`、Kyoko で作成した合成音声） |

同じデータを `yamanote.html` 内にも埋め込み、「おと」設定に従って再生します。
