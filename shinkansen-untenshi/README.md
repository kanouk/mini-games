# しんかんせん うんてんし

新幹線が大好きな子どものための、失敗のないブラウザ運転ゲームです。1つのHTMLファイルだけで動きます。

## 遊び方

- タイトル画面で「はじめる」を押すと始まります。「ろせんを えらぶ」から乗る路線を先に選ぶこともできます。ゲーム中は「タイトル」ボタンでタイトル画面に戻れます。
- 「しゅっぱつ！」を押すと発車ベルが鳴り、ドアが閉まって走り出します。押し続けると加速し、駅に近づくと自動で止まります。
- 押し続けたままにすると、乗り降りが終わったあと自動で次の駅へ向かいます。
- 「じどう」をオンにすると、ボタンを押さなくても走ります。

## できること

- 13路線（東海道・山陽・九州・西九州・東北・北海道・山形・秋田・上越・北陸、直通の東海道・山陽／山陽・九州／東北・北海道）
- 乗る駅・降りる駅・出発時刻・止まる駅（各駅／速い電車）を選べる
- 時刻表（通過駅は「レ」）、時計、遅れの表示と回復運転
- 車内チャイム・日本語と英語のアナウンス・車内表示器、車掌さんの声、警笛
- 緊急停止（理由を選べる）
- 「じんしんじこ」は救護・安全確認のため、ゲーム内で90分の遅れが付きます。90分はゲーム用の目安で、実際の事故の平均時間ではありません。
- 緊急停止の実際の待ち時間は、今回増える遅れの分数に対する対数式 `round(7 × ln(1 + 分数) / ln(4))` で短縮します。3分で7秒、8分で11秒、90分で23秒です（アナウンス中は最大9秒延長）。
- 区間ごとの最高速度、0時〜6時は新幹線区間を走らないルール
- 区間ごとの景色、時刻による空の色、現在地の地図
- 駅での乗り降り、車体の色えらび、全画面表示
- 停車の約8％で、乗ろうとした人が1人だけつまずき、「あっ！」と声を出します。起き上がって電車を見送ります。音声は西武線ゲームと共通で、「おと」設定に従います。

## 3Dモード（裏コマンド）

- タイトル画面の何もないところを **10回続けてタップ（クリック）** すると、景色を立体で描く3Dモードに切り替わります。もう一度10回タップすると元の2Dに戻ります。選んだモードは次回も引き継がれます。
- 遊べること・操作・時刻・音は2Dとまったく同じです。変わるのは絵（列車・駅・景色・空・人）と、画面の表示のデザイン（落ち着いた配色）だけです。警笛や車掌さんの吹き出しは3Dでは出しません（音は鳴ります）。
- 3Dモードは `shinkansen-3d.js` と `vendor/three.module.min.js`（[three.js](https://threejs.org/) r170、MITライセンス）を、切り替えたときにだけ読み込みます。そのため **HTTPサーバー経由（GitHub Pages など）で開いたときだけ** 使えます。ファイルを直接開いた場合や WebGL が使えない端末では、2Dのまま遊べます。
- 動きが重い端末では、自動で描画の解像度を下げます。

## ファイル

| ファイル | 内容 |
|---|---|
| `shinkansen.html` | ゲーム本体（HTML・CSS・JavaScriptを1ファイルにまとめたもの） |
| `shinkansen-3d.js` | 3Dモードの描画（ゲームの進行は `shinkansen.html` のまま） |
| `vendor/three.module.min.js` | three.js r170（3D描画ライブラリ。ライセンスは `vendor/three.LICENSE`） |
| `tests/schedule.test.js` | 時刻のルールを確かめる自動テスト |
| `tests/passengers.browser.html` | つまずき・見送り・次駅への運転を確かめるブラウザテスト |

## テスト

```sh
node tests/schedule.test.js
node tests/emergency.test.js
```

ブラウザテストは HTTP サーバー経由で `tests/passengers.browser.html` を開いて実行します。`?preview=fall`・`?preview=missed` で演出を静止表示できます。本番用の保存データは変更しません。

## 注意

- 時刻は、駅間の距離と最高速度から計算した目安です。本物の時刻表ではありません。
- 新幹線の絵は、特定の車両に似せないオリジナルのデザインです。
- 停車駅は [tabiris「新幹線停車駅一覧」](https://shinkansen.tabiris.com/teisya00.html) を参考にしています。
- 地図の海岸線は [Natural Earth](https://www.naturalearthdata.com/)（1:50m）を簡略化したものです。
