# しんかんせん うんてんし

新幹線が大好きな子どものための、失敗のないブラウザ運転ゲームです。1つのHTMLファイルだけで動きます。

## 遊び方

- タイトル画面で「はじめる」を押すと始まります。「ろせんを えらぶ」から乗る路線を先に選ぶこともできます。ゲーム中は「タイトル」ボタンでタイトル画面に戻れます。
- 「しゅっぱつ！」を押すと発車ベルが鳴り、ドアが閉まって走り出します。押し続けると加速し、駅に近づくと自動で止まります。
- 押し続けたままにすると、乗り降りが終わったあと自動で次の駅へ向かいます。
- 「じどう」をオンにすると、ボタンを押さなくても走ります。

## できること

- 13路線（東海道・山陽・九州・西九州・東北・北海道・山形・秋田・上越・北陸、直通の東海道・山陽／山陽・九州／東北・北海道）
- 乗る駅・降りる駅・出発時刻・止まる駅（各駅／速い電車）を選べる
- 時刻表（通過駅は「レ」）、時計、遅れの表示と回復運転
- 車内チャイム・日本語と英語のアナウンス・車内表示器、車掌さんの声、警笛
- 緊急停止（理由を選べる）
- 区間ごとの最高速度、0時〜6時は新幹線区間を走らないルール
- 区間ごとの景色、時刻による空の色、現在地の地図
- 駅での乗り降り、車体の色えらび、全画面表示

## ファイル

| ファイル | 内容 |
|---|---|
| `shinkansen.html` | ゲーム本体（HTML・CSS・JavaScriptを1ファイルにまとめたもの） |
| `tests/schedule.test.js` | 時刻のルールを確かめる自動テスト |

## テスト

```sh
node tests/schedule.test.js
```

## 注意

- 時刻は、駅間の距離と最高速度から計算した目安です。本物の時刻表ではありません。
- 新幹線の絵は、特定の車両に似せないオリジナルのデザインです。
- 停車駅は [tabiris「新幹線停車駅一覧」](https://shinkansen.tabiris.com/teisya00.html) を参考にしています。
- 地図の海岸線は [Natural Earth](https://www.naturalearthdata.com/)（1:50m）を簡略化したものです。
