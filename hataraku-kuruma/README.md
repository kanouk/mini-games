# はたらく くるま しゅつどう

未就学児向けの、働く車が小さな街で出動するゲームです。1つのHTMLファイルだけで動きます。文字が読めなくても、声・音・光るヒントだけで遊べます。

## 遊び方

1. **じけんが おきる** — ベルが鳴り、街のどこかで火事・泥棒などが起きます。声で「たいへん！ かじだ！ だれが たすけに いくかな？」と知らせます。
2. **くるまを えらぶ** — 下の大きなボタンから、事件に合う車を選びます。違う車を選ぶと、その車が得意なことを声で教えます（怒られません）。2回違うと正解の車が光ります。
3. **みちを えらぶ** — 車が自分の基地（消防署・警察署・病院・車庫）から出発します。行きたい方向の画面をタップすると、1区画ずつ進みます。黄色く光る場所がゴールです。
   - 工事中の道は通れません。別の道を探します。
   - 道の上の星を拾うと集まります（遠回りしても楽しい）。
   - 8秒ほど迷うと、近道の矢印が黄色く光ります。
4. **げんばで たすける** — 着いたら画面をタップして助けます。終わると紙ふぶきとステッカーがもらえます。5回ごとに全員のパレードがあります。

## 事件と車

| 事件 | 車 | 現場ですること |
|---|---|---|
| かじ | しょうぼうしゃ | 4回タップして水をかける |
| ねこが きから おりられない | しょうぼうしゃ | はしごを伸ばして助ける |
| どろぼう | パトカー | 1回逃げるので追いかけて、タップで捕まえる |
| けがを した こ | きゅうきゅうしゃ | 乗せてから病院まで道を選んで運ぶ |
| ごみが いっぱい | ごみしゅうしゅうしゃ | 3回タップして集める |
| いわが ころがってきた | ショベルカー | 3回タップしてどかす |

最初の3回は消防車・パトカー・救急車の3台だけで、だんだん5台・工事中の道が増えます。

## そのほか

- 画面の向きで街の並べ方が変わります（スマホ縦でも大きく表示）。
- 左上：タイトルへ戻る／もういちど声を聞く。右上：集めた星／音のオン・オフ。
- キーボードでは矢印キーで進み、スペースで現場のタップになります。
- ステッカーと星は端末に保存されます。
