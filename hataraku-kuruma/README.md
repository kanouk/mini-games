# はたらく くるま しゅつどう

未就学児向けの、働く車が小さな街で出動するゲームです。1つのHTMLファイルだけで動きます。文字が読めなくても、声・音・光るヒントだけで遊べます。

## 遊び方

1. **じけんが おきる** — ベルが鳴り、街のどこかで火事・泥棒などが起きます。声で「たいへん！ かじだ！ だれが たすけに いくかな？」と知らせます。
2. **くるまを えらぶ** — 下の大きなボタンから、事件に合う車を選びます。違う車を選ぶと、その車が得意なことを声で教えます（怒られません）。2回違うと正解の車が光ります。
3. **みちを えらぶ** — 車が自分の基地（消防署・警察署・病院・車庫）から出発します。車をつかんで道路に沿ってドラッグするか、行きたい方向の画面をタップすると進みます。黄色く光る場所がゴールです。
   - ドラッグでは交差点で曲がったり、そのまま複数区画を進んだりできます。指を離すと近くの交差点に収まります。
   - 工事中の道は通れません。最初の2回は通行止めなし、その後は1か所・2か所・最大3か所へ増えます。必ず目的地までつながるように選びます。
   - 道の上の星を拾うと集まります（遠回りしても楽しい）。
   - 8秒ほど迷うと、近道の矢印が黄色く光ります。
4. **げんばで たすける** — 着いたら画面をタップして助けます。終わると紙ふぶきとステッカーがもらえます。5回ごとに全員のパレードがあります。

## 事件と車

| 事件 | 車 | 現場ですること |
|---|---|---|
| かじ | しょうぼうしゃ | 4回タップして水をかける |
| ねこが きから おりられない | しょうぼうしゃ | はしごを伸ばして助ける |
| どろぼう | パトカー | 1〜3回逃げるので追いかけて、タップで捕まえる |
| けがを した こ | きゅうきゅうしゃ | 乗せてから病院まで道を選んで運ぶ |
| ごみが いっぱい | ごみしゅうしゅうしゃ | 3回タップして集める |
| いわが ころがってきた | ショベルカー | 3回タップしてどかす |

泥棒の逃走回数は事件ごとに決まり、65%で1回・25%で2回・10%で3回です。逃げる先も通行止めを避けて選びます。

最初の3回は消防車・パトカー・救急車の3台だけで、だんだん5台・工事中の道が増えます。

## そのほか

- 画面の向きで街の並べ方が変わります（スマホ縦でも大きく表示）。
- 左上：タイトルへ戻る／もういちど声を聞く。右上：集めた星／音のオン・オフ。
- マウス・タッチのドラッグ、画面のタップ、矢印キーで進めます。スペースは現場のタップになります。
- ドラッグのキャンセル、タイトルへの帰還、画面の向きの変更では車が道路に戻り、つかんだ状態が残らないようにしています。
- ステッカーと星は端末に保存されます。
- ゲーム用の生成スプライト19枚を内蔵しています。走行の揺れ、ランプ、放水・回収、救助の進み具合も画面で分かります。
- 道路は街区をくり抜いた一枚の形として描き、交差点の中に縁取りが残らないようにしています。
- 端末の「視差効果を減らす」設定に対応しています。

## ファイル

| ファイル | 内容 |
|---|---|
| `kuruma.html` | ゲーム本体（HTML・CSS・JavaScriptを1ファイルにまとめたもの） |
| `tests/town.test.js` | 街の道・事件の決め方を確かめる自動テスト |
| `tests/browser.test.html` | 6事件のドラッグでの救助・1〜3回の逃走・キャンセル・通行止め・車の向き・画面サイズを実ブラウザーで検証 |
| `assets/` | 生成画像・最終プロンプト・原画像との対応表 |
| `scripts/embed-art.js` | WebPをHTMLに内蔵する更新用スクリプト |

## テスト

```sh
node tests/town.test.js
```

HTTPサーバーで開いた `tests/browser.test.html` の「テストを実行」から、実際のゲーム本体を使うブラウザーテストを実行できます。テストは保存先を分け、走行時間だけを短縮します。

400×844、1024×768、320×568、844×390の画面で、交差点に縁取りが重ならないこと、建物が道路の外にあること、操作ボタンが収まることを検証します。
